# Session 10 — Questions and Answers

## 1. What is the difference between a build and a deployment?

A build creates optimized application files. A deployment uploads/hosts those files so people can access them online.

## 2. What is the `dist` folder?

It is the usual Vite output folder containing the production build. It is not the source code and is generally generated by the build command.

## 3. Why is a Vite `VITE_` variable not a secret?

Values with the `VITE_` prefix can be included in browser code. Visitors can inspect them. Never put service-account keys or privileged credentials there.

## 4. What is an SPA fallback?

It tells the host to serve the app entry page for client-side routes such as `/blogs/example`, so React Router can choose the correct view.

## 5. What is a smoke test?

A quick check that the most important production paths work, such as opening the site, signing in, reading a public post, and reaching admin pages with the correct role.

## 6. Why test security rules separately from the page?

A page may hide a control while the database still allows the operation. Direct rule tests check the actual data boundary.

## 7. Practice: The homepage works, but refreshing `/blogs/java` shows a 404. What might be missing?

**Answer:** The hosting platform may not have the SPA fallback configured for React Router.

## Troubleshooting: Local Firebase works but production sign-in fails. What should you compare?

Check production environment values, authorized domains, deployed Firebase configuration, hosting URL, browser console/network errors, and Firebase rules. Do not paste secrets into logs or screenshots.
